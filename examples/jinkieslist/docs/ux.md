## Summary

JinkiesList is a phone-first app with two places: the list, for shopping, and the
pantry, for what is at home. Both open in one tap from the tab bar. The list
must be usable one-handed in a store aisle, with no connection, so every
action on it is a single tap and no action waits on the network.

## Flows

<a id="flw-01"></a>
### FLW-01 — Shop from the list

- **Goal:** buy everything on the list and record it at home
- **Requirements:** [R-LIST-01](prd.md#r-list-01), [R-PANTRY-01](prd.md#r-pantry-01)
- **Starts:** [SCR-01](#scr-01) with unchecked items
- **Ends:** [SCR-01](#scr-01) with the bought items checked and in the pantry

1. The member taps an item's checkbox. It checks at once, online or not.
2. A snackbar offers "Add to pantry"; tapping it adds the item with its
   quantity. The snackbar leaves after 5 seconds.
3. Checked items collect under a "Bought" divider at the bottom.

<a id="flw-02"></a>
### FLW-02 — Join a household

- **Goal:** get onto a household's shared list
- **Requirements:** [R-LIST-03](prd.md#r-list-03)
- **Starts:** an invitation link opened on a phone
- **Ends:** [SCR-01](#scr-01) showing the household's list

1. The link opens [SCR-03](#scr-03) with the household's name.
2. The person taps Join. If the link has expired or was revoked, the screen
   says so and asks them to request a new one.

## Screens

<a id="scr-01"></a>
### SCR-01 — List

- **Purpose:** see and check off what to buy
- **Requirements:** [R-LIST-01](prd.md#r-list-01), [R-LIST-02](prd.md#r-list-02)
- **Roles:** every member
- **Entry:** the List tab; the app's home
- **States:** default, empty, loading n/a, error n/a, offline, conflict

An add field sits at the top, then unchecked items in the order added, then
the Bought divider. Each row uses [CMP-01](#cmp-01).

- **Default:** unchecked items, then the Bought divider.
- **Empty:** a single line, "Nothing to buy", above the add field's focus.
- **Offline:** a quiet banner, "Offline — changes will sync", and nothing
  else changes.
- **Conflict:** the affected row shows both values and asks which to keep.

<a id="scr-02"></a>
### SCR-02 — Pantry

- **Purpose:** see what is at home and what expires soon
- **Requirements:** [R-PANTRY-01](prd.md#r-pantry-01), [R-PANTRY-02](prd.md#r-pantry-02)
- **Roles:** every member
- **Entry:** the Pantry tab
- **States:** default, empty, loading n/a, error n/a, offline

- **Default:** entries expiring within 3 days come first under "Use soon",
  styled by [VR-01](#vr-01). The rest follow alphabetically.
- **Empty:** "Nothing in the pantry yet", and a link to the list.
- **Offline:** the same banner as [SCR-01](#scr-01).

<a id="scr-03"></a>
### SCR-03 — Join household

- **Purpose:** accept an invitation
- **Requirements:** [R-LIST-03](prd.md#r-list-03)
- **Entry:** an invitation link
- **States:** default, loading, error, offline

- **Default:** the household's name and a Join button.
- **Loading:** a spinner while the link is checked.
- **Error:** the link has expired or was revoked; ask for a new one.
- **Offline:** "Connect to join", with a retry button.

<a id="scr-04"></a>
### SCR-04 — Staples

- **Purpose:** choose which pantry entries JinkiesList keeps in stock
- **Requirements:** [R-PANTRY-03](prd.md#r-pantry-03)
- **Roles:** household organizer
- **Entry:** Pantry, then the Staples button
- **States:** default, empty

- **Default:** each staple with its restock quantity.
- **Empty:** a short explanation of staples and an Add button.

## Components

<a id="cmp-01"></a>
### CMP-01 — Item row

- **Purpose:** one item, with a checkbox a thumb can hit
- **States:** unchecked, checked, pending sync, conflict
- **Used by:** [SCR-01](#scr-01), [SCR-02](#scr-02)

The whole row is the tap target for checking, at least 48 points tall.
Pending sync shows a small clock icon; it never blocks interaction.

## Visual rules

The authoritative token source is `design/tokens.json`. This document names
tokens and never copies their values.

<a id="vr-01"></a>
### VR-01 — Expiring entries

- **Applies to:** pantry entries expiring within 3 days
- **Tokens:** `color.warning.surface`, `color.warning.text`

Colour is never the only signal: the entry also shows "Expires in N days".

## Accessibility

- Every action is reachable with a screen reader and a switch control.
- Text meets WCAG 2.2 AA contrast in light and dark themes.
- Animations respect the system's reduce-motion setting.
